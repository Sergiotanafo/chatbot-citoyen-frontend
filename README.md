# Chatbot Citoyen Malien — Frontend

## 1. Présentation du projet

Ce dépôt contient la partie frontend du projet **Chatbot Citoyen Malien**, une plateforme conversationnelle destinée à faciliter l'accès des citoyens maliens aux informations et services publics.

L'application vise à proposer une expérience accessible, intuitive et bilingue (français et bambara).

## 2. Objectifs

- Permettre aux citoyens d'interagir avec le chatbot.
- Faciliter l'accès aux informations administratives.
- Proposer une interface adaptée aux ordinateurs, tablettes et téléphones.
- Offrir une interface d'administration pour gérer la plateforme.

## 3. Architecture du frontend

Le frontend est organisé autour de deux interfaces :

- **Chatbot UI :** interface de conversation avec les citoyens.
- **Admin UI :** tableau de bord destiné aux administrateurs.

## 4. Fonctionnalités prévues

### Interface citoyenne
- Interface de discussion avec le chatbot.
- Affichage de l'historique des conversations.
- Prise en charge du français et du bambara.
- Interaction textuelle et, selon les fonctionnalités intégrées, vocale.

### Interface d'administration
- Tableau de bord.
- Gestion des utilisateurs.
- Gestion des contenus et informations.
- Suivi des conversations et des activités.
